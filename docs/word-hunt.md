# Word Hunt

Guess a hidden Russian or English word. Every guess marks its letters: green in place, amber
elsewhere in the word, grey not in it (repeated letters count only as often as the word has them).

## Modes

- **Alone** (1 seat): a number of guesses from the settings (4–8). Unlimited words, or the **word
  of the day** (5 letters, the same for everyone that day; the client supplies the day number,
  the game has no clock). Local stats per language (`client/src/games/word-hunt/stats.ts`).
- **Group** (2–4 seats, people or bots): the players take turns on one board in seat order;
  whoever finds the word wins. The **first turn** setting picks who starts: random, the host (the
  player in a local game) first, or the host last (the seat after the host starts, so the host
  closes each round); a first-player event that contradicts it is refused. There is no guess
  limit to play to, only a safety cap of 30 guesses in total (`GROUP_GUESS_CAP`) that ends the
  game as a draw with the word shown. No turn timer. The word of the day is not available in a
  group.
- **Hard mode** (any mode): every guess must keep the green letters in place and use the letters
  found.
- **Give up** at any time: alone it is a loss and the word is shown; in a group the seat drops out
  and the others play on. When one seat is left it wins; when the last person leaves a table with bots the game stops
  (a table of bots only, as in the arena, plays on).

A guess must be a word of the right length in the language's alphabet and not tried before. Whether
it is a real word is the client's check against the word list: the rules only need the letters, so
replays never depend on a word list version.

The word is the authority's secret (`HiddenWord`, see architecture.md). No client has it while
the game runs, not even in a group game online:
- the first frame says only that a word was chosen;
- each guess is marked by the authority in the same frame;
- the word itself is sent once the game is over, as an event holding the word, so replays show
  it.

The word of the day is the exception by nature: it follows from the day and the built-in list, so
a client could work it out. It is played alone, so there is nobody to hide it from.

Replays recorded before the word was kept secret carried the word at the start; they are no
longer accepted.

## Bots

`GuessingBot` picks a random answer that fits the hints its level takes into account, and never
reads the answer: easy uses every hint of the last two guesses, medium the green and yellow
letters of every guess, hard every hint. In hard mode it only plays guesses the rule allows.

## Word lists

Generated by `tools/word-lists/generate.py` (sources, licenses and thresholds in its README): the
answers are built into the game crate, the full list of accepted guesses is a static file the
client loads when the game starts (cached by the service worker, updated with the web bundle).

## Compatibility

Since the word became a secret, replays from before it are refused; hashes changed with it.
